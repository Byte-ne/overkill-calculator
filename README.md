# Overkill Calculator

This project is a React + TypeScript “overkill” calculator (basic/scientific/programming/graphing + panels).

## Run it (recommended: install Node.js)

1. Install **Node.js LTS** (this provides `node` and `npm`).
2. In this folder, run:

```bash
npm install
npm start
```

## Run it *without* Node.js (serve the existing build)

If you already have a compiled build in `build/`, you can serve it with Python:

```bash
python -m http.server 4173 --directory build
```

Then open `http://localhost:4173`.

## Notes

- If `npm` is “not recognized”, Node.js is not installed or not on your PATH yet.
